# 小甜水使用手册（简版）

官方刷机页：<https://ethanyan6.github.io/Syrup/>  
仓库：<https://github.com/EthanYan6/Syrup>

## 1. 浏览器要求

请使用 **Chrome / Edge / Opera**（需 Web Serial）。

## 2. 推荐刷机顺序

1. **备份校准**（原厂或首次刷入前备份一次即可）
2. **刷固件**（关机后按住 PTT 开机进入 BOOT）
3. **刷字库**（正常开机界面下刷入 `cn_font.bin`，地址 `0x024000`）
4. **恢复校准**（本站读写固定 **`0xB000`**）
5. **写频**（按需，正常开机界面）
6. **基础信息**（按需：上行码 / 下行码 / 开机页最后一行，正常开机界面）

## 3. 注意事项

- 仅适用于泉盛 **UV-K1 / UV-K5(K6) V3**。老版本 K5/K6 可能变砖。
- 刷固件需 BOOT 模式；刷字库、校准、写频、基础信息均在**正常使用界面**下连接 USB。
- 校准备份/恢复：本站固定使用 **0xB000**（512 字节，v5 校准区）。
- 字库与叮咚鸡同源格式，有更新时请重新刷入。

## 4. 双 PTT

开启后：硬件 PTT 打 **CH1**，侧键 1 打 **CH2**。谁在发射，主页对应信道就会反色，松开后主信道留在刚发射的那条，可继续操作。

### 如何开启

1. 打开菜单，进入 **侧键1短按**（或 **侧键1长按**）。
2. 选 **PTT**，确认保存。另一个槽位会自动同步为 PTT。
3. 建议把菜单里的 **设置 PTT** 设为 **经典**（按住说话）。双 PTT 开启后固件也会把它改回经典。

**PTT** 只出现在侧键 1 的短按/长按里。侧键 2、MENU 长按列表没有这一项。

不要和 **设置 PTT**（经典 / 一键）搞混：那一项只改**硬件 PTT** 是按住说话还是按一下开关，不会打开双 PTT。

### 怎么用

| 按键 | 效果 |
|------|------|
| 硬件 PTT 按住 | CH1 发射，主页 CH1 反色 |
| 侧键 1 按住 | CH2 发射，主页 CH2 反色 |
| 两键同时按住 | 硬件 PTT 优先，打 CH1 |
| 松开 | 停止发射 |

侧键 1 整颗都当 CH2 的 PTT（按下发射、松开停止）。开启后，侧键 1 上原来绑的短按/长按动作不会再触发。

### 如何关闭

把 **侧键1短按** 或 **侧键1长按** 改成别的动作（例如「无」）。两个槽位会一起变成 **无**，之后可以再分别设置。
